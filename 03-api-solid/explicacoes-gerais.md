### Diferença em ?? e ||

O operador **??** é utilizado para definir um valor padrão caso a variável seja `nula` ou `indefinida`.

Já o operador **||** é utilizado para definir um valor padrão caso a variável seja `falsy (false, 0, "", null, undefined, NaN)`.

Em resumo **??** é para lidar com valores `nulos` ou `indefinidos`, enquanto **||** é para lidar com valores `falsy`.
